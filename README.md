# Платформа для отслеживания и симуляции торговли валютами

## Общая идея проекта
Проект представляет собой комплексную платформу для симуляции торговли фиатными и криптовалютами. Пользователи могут:

- Регистрироваться и управлять аккаунтом.
- Создавать и вести виртуальные портфели валют.
- Совершать сделки покупки и продажи валют.
- Отслеживать актуальные курсы в реальном времени.
- Анализировать историю своих транзакций.

Система состоит из двух основных сервисов:

1. **Сервис Парсинга (Parser Service)**  
   Отдельное приложение, которое обращается к публичным API по расписанию или запросу, получает актуальные курсы валют, сравнивает их с предыдущими значениями и сохраняет историю в базу данных.

2. **Основной Сервис (Core Service)**  
   Главное приложение, предоставляющее пользовательский интерфейс (CLI), управляет пользователями, кошельками и транзакциями. Обменивается данными с сервисом парсинга для получения актуальных курсов.

## Установка

1. Клонировать репозиторий:
```commandline
git clone URL репозитория
cd finalproject_kogay-sergey_m255-55
```

2. Установить зависимости через Poetry:
```commandline
make install
```

3. Активировать виртуальное окружение:
```commandline
poetry shell
```

## Запуск проекта
```commandline
make project
```
